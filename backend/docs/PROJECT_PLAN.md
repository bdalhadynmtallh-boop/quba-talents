# خطة مشروع موهوبين ثانوية قباء

تاريخ القرار: 2026-10-10. مشروع من ثلاثة أجزاء؛ أجاز المستخدم الجزء الثالث الآن داخل المشروع الحالي.

## المتطلبات والقرارات

- React + Vite + TypeScript strict، React Router، Tailwind 4، Lucide. العربية RTL وخطوط محلية ووضعان بالألوان عبر CSS variables.
- Fastify 5، PostgreSQL 17، Prisma 7 (إصدار مستقر مثبت، driver adapter pg)، Zod، npm workspaces.
- لا حسابات للطلاب. التسجيل العام يرسل طلبًا فقط. بيانات الطلاب والأعمال والإعدادات والمرفقات للمسؤول حصريًا.
- جلسات قاعدة بيانات مع hash للرمز، كوكيز موقعة HttpOnly/SameSite Strict وSecure/__Host في الإنتاج، CSRF بتوكن موقّع وOrigin مطابق.
- تخزين الملفات محلي في مسار مستقل دائم عند النشر؛ أسماء عشوائية، تحقق من البنية، إعادة ترميز الصور، وPDF تنزيل فقط.
- حذف الملفات عبر قائمة حذف محفوظة في قاعدة البيانات ومعالجة متكررة، وتسوية ملفات غير مرتبطة بعد مهلة احترازية. لا جلب تلقائي للروابط الخارجية.
- قبول التسجيل يقفل صف الطلب داخل معاملة قبل تحويله إلى طالب؛ الاعتماد المتكرر يعيد الطالب نفسه.
- الإنجازات بيانات منظمة (عنوان وتاريخ اختياري). مشرفو الطالب اختيار خاص أو وراثة إعدادات المدرسة.
- المسودة والسيرة المعتمدة حقلا JSON منفصلان، مع cvSchema version=2 ولقطة هوية وبصمة مصدر وrevision. اتصال النموذج والـPDF أضيفا في الجزء الثالث؛ لم يكونا ضمن تنفيذ الجزء الثاني.
- خدمة النص native fetch إلى Qwen، بإعدادات خادم مستقلة ومخرجات منظمة مدعومة حسب المزود والمنطقة وتحقق Zod. لا بيانات شخصية غير لازمة أو مرفقات، ولا إعادة محاولات تلقائية أو توليد عند القراءة والتنزيل. القفل المؤقت محفوظ في PostgreSQL، وحدود التزامن المحلية AI=2 وPDF=1.
- التصدير من المعتمد فقط، Chromium مع خطوط مضمنة ونص آمن وشبكة محظورة، وخرائط Unicode للعربية القابلة للبحث. دفعة 1–20 مع فهرس وبداية صفحة لكل طالب. هوية المعتمد ثابتة حتى اعتماد جديد، وشعار المدرسة الحالي يأتي من التخزين الخاص.
- حفظ ثلاثة مشرفين بأسمائهم الحقيقية وترتيبهم في قاعدة إعدادات المدرسة، وإضافة شعار وزارة التعليم السعودية إلى رأس المعاينة وPDF. الشعار من حزمة الوزارة الرسمية محفوظ في backend/assets/branding ومع الواجهة في frontend/src/assets؛ لا تحميل شبكة عند التصدير ولا أسماء حقيقية ثابتة في المصدر.
- طلب إعادة التنظيم: مجلدان رئيسيان frontend وbackend، مع shared والتوثيق وأداة إعداد البيئة تحت backend وملفات تشغيل مشتركة بالجذر. تبقى npm workspaces والتقنيات الحالية؛ حدّثت المسارات دون إعادة إنشاء البيانات. المنفذ المحلي الافتراضي 5186 متطابق مع APP_ORIGIN.

## الأجزاء

1. الأساس: workspaces وCompose ومخطط وترحيل أول، المصادقة، الثيم، الرئيسية والتخطيطات والتوثيق والتحقق.
2. الطلاب مع pagination وبحث وتصفية، التسجيل والمراجعة، الأعمال والمرفقات، إعدادات المدرسة والمشرفين، وتجهيز مصدر السيرة.
3. اتصال Qwen مباشر من services/ai بإعدادات AI_API_KEY/AI_BASE_URL/AI_MODEL/AI_TIMEOUT_MS. الناتج summary/talents/skills/achievements/projects/missingInformation، مع منع الاختلاق وعدم إرسال المرفقات أو الاسم/الصف/المشرفين. تحرير مسودة واعتمادها دون استبدال المعتمد عند إعادة الصياغة، وتنبيه عند تغير المصدر. PDF من المعتمد فقط بقالب A4 أبيض RTL وخطوط محلية عبر Playwright/Chromium، تنزيل منفرد أو دفعة محدودة للطلاب المحددين أو نتائج التصفية مع فهرس وبداية صفحة لكل طالب. لا صوت ولا n8n ولا نشر تلقائي.

## البنية

- frontend/src/{app,pages,features,components/ui,components/layout,lib,styles,assets}
- backend/src/{config,plugins,modules,services,lib} وapp.ts/server.ts
- backend/prisma/{schema.prisma,migrations,seed}
- backend/shared/src: أنواع استجابات API ومخططات Zod ومخطط السيرة.
- backend/assets/branding وfrontend/src/assets: شعار وزارة التعليم المحلي للخادم والواجهة ومصدره الرسمي.
- backend/docs: الخطة والتقدم وصور المتصفح ونماذج PDF الاختبار. README الرئيسي للتشغيل السريع وfrontend/README وbackend/README لملفات كل قسم والتهيئة والنسخ الاحتياطي. خدمات AI/PDF فعلية وليست طبقات فارغة.

## تدقيق بدء الجزء الثاني

لم تكن README وPROGRESS وPROJECT_PLAN موجودة لأن طلب الجزء الثاني وصل أثناء تحقق الجزء الأول. كود الطلاب والتسجيل كان يعيد 501 والمعاينات ثابتة وموسومة. كانت قاعدة PostgreSQL المحلية فارغة؛ الترحيل الأول محفوظ ولم يُطبق بعد. عولجت النواقص بوظائف حقيقية وأربعة ترحيلات مطبقة واختبارات قاعدة ومصادقة ومتصفح وPDF. Docker Desktop يتعطل داخليًا؛ PostgreSQL محمول تحت work يشغّل المعاينة والاختبارات المحلية فقط. الحالة النهائية ونتائج التحقق وحدودها في PROGRESS؛ اتصال Qwen الحقيقي ينتظر مفتاحًا صالحًا.
