# النشر: Vercel للواجهة وRender للخادم

مصدر الواجهة في frontend، والخادم في backend. قاعدة PostgreSQL والمرفقات تبقى خاصة؛ المفتاح في بيئة الخادم فقط.

## الخادم

backend/Dockerfile يبني الخادم وshared ويثبت Chromium ومكتبات Linux لتصدير PDF. يبدأ بالترحيلات ثم يستمع على 0.0.0.0 وPORT. لا تُنسخ أسرار البيئة أو ملفات الطلاب إلى الصورة.

backend/render.yaml إعداد مقترح لخادم 512 MB وقاعدة 256 MB وقرص مرفقات 1 GB في فرانكفورت. هذه موارد مدفوعة؛ لا تُنشأ قبل موافقة صاحب الحساب. حجم 512 MB يحتاج تحققًا من استهلاك Chromium بعد النشر، وقد يلزم رفع الخطة للسير الطويلة. لا يوجد نشر ناجح متحقق حتى تسجيل رابط الخدمة ونتائج الفحص هنا.

Render يحتاج مستودع Git يمكنه قراءته، ومسار Blueprint هو backend/render.yaml. يحدد APP_ORIGIN بأصل رابط الواجهة الإنتاجي دون شرطة أخيرة، وتضاف AI_API_KEY كسر، ويُولّد COOKIE_SECRET مستقلًا عن التطوير.

STORAGE_DIR=/var/data/uploads داخل القرص الدائم. القرص متاح أثناء التشغيل فقط، ويقيد الخادم بنسخة واحدة مع انقطاع قصير عند إعادة النشر. التخزين المؤقت لا يحفظ مرفقات الطلاب. قبل الاستخدام الفعلي يلزم نسخ PostgreSQL والمرفقات وخطة استرجاع.

## الواجهة

مشروع Vercel من جذر المستودع، Node 24، installCommand=npm ci، buildCommand=npm run build -w @quba/shared && npm run build -w @quba/web، outputDirectory=frontend/dist. لا يتطلب بناء الواجهة توليد Prisma أو اتصال قاعدة.

مسارات /api و/health تُوجّه عبر rewrite إلى رابط Render الصحيح، ثم مسارات التطبيق إلى index.html. يبقى الطلب على أصل الواجهة لتعمل جلسة Secure/HttpOnly وCSRF وOrigin. لا تضف مفتاح AI إلى VITE_* أو الواجهة. لا تفعل تخزين ردود API في CDN.

يلزم اختبار تسجيل الدخول، CSRF، إرسال التسجيل، ورفع 10 MiB وتنزيل PDF عبر رابط Vercel؛ نجاح البناء وحده لا يثبت صحة الربط. مهلة rewrite الخارجية في Vercel 120 ثانية؛ مهلة AI/PDF في التطبيق 60 ثانية. حدود IP خلف سلسلة الوكلاء تحتاج تحققًا فعليًا، والخادم الحالي لا يثق بترويسات IP التي يرسلها العميل.

## نقل النسخة الحالية

الحزمة والمستودع يستثنيان القاعدة و.env والمرفقات. لن تظهر أسماء المشرفين والطلاب الحالية في قاعدة جديدة تلقائيًا؛ تُنقل قاعدة المشروع والمرفقات بشكل خاص أو تُدخل الإعدادات عبر المسؤول. يُنشأ مسؤول إنتاج بكلمة مرور مستقلة، ولا تُنشر بيانات دخول المعاينة.
