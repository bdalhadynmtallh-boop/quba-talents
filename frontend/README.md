# الواجهة Frontend

React وVite وTypeScript، عربية RTL وخطوط محلية وثيمان وجوال. لا مفاتيح AI ولا اتصال مباشر بقاعدة البيانات هنا.

```text
frontend/
  src/pages/           الرئيسية والدخول والتسجيل والطلاب والملف
  src/features/        نماذج الطلاب والطلبات والأعمال والمدرسة والسيرة
  src/components/      التخطيط والنوافذ والتأكيد وحالات التحميل
  src/app/             التوجيه والثيم
  src/lib/             HTTP وCSRF والموارد وتنزيل PDF
  src/styles/          الألوان وRTL والتجاوب
  src/assets/          الرسم وشعار الوزارة المحلي
  tests/               رحلات المتصفح
  vite.config.ts       المنفذ 5186 وتوجيه API إلى 3001
```

من جذر المشروع شغّل `npm run dev` لتشغيل الواجهة والخادم معًا. للتشغيل المنفصل بعد بناء shared: `npm run dev -w @quba/web`؛ تحتاج API تعمل على 3001. البناء في frontend/dist.

لتعديل السيرة المعروضة: src/features/cv/CvPaper.tsx (مشترك بين العرض والمعاينة المباشرة) وCvPreview.tsx وCvEditor.tsx وstyles/cv.css. قالب PDF المطبوع مستقل في backend/src/services/pdf/template.ts، والترويسة الرسمية مشتركة النص من @quba/shared.

الرئيسية في src/pages/HomePage.tsx وstyles/home.css، مع دعم تقليل الحركة. مؤشر اكتمال توثيق الملف في src/features/students/ProfileCompletion.tsx، وليس تقييمًا للموهبة. نتائج مراجعة هذه التحسينات والصور وعينات PDF في [تقرير المراجعة](../backend/docs/REVIEW_2026-10-10.md).

شعار الوزارة في src/assets/ministry-education.png نسخة من الأصل الرسمي الموثق في backend/assets/branding/README.md؛ لا يتطلب اتصالًا بموقع الوزارة. المخططات التي تستعملها الواجهة تأتي من حزمة @quba/shared داخل backend/shared.

## النشر

إعدادات المدرسة تتضمن السنة الدراسية والفصول والمواهب وترتيبها وتعطيلها. يكتب الطالب الفصل والموهبة الرئيسية والمواهب الإضافية مباشرة في التسجيل، وكذلك المسؤول عند إضافة الطالب وتعديله ومراجعة الطلب. المواهب الإضافية اختيارية، كل موهبة في سطر، حتى 10 دون تكرار. صفحة الطلاب تعرض لوحة السنة المفتوحة والبحث باسم الطالب؛ أُزيلت قوائم التصفية من شريط البحث بطلب المستخدم. تبقى بطاقات اللوحة قابلة للنقر لعرض الطلاب المقابلين لها، ويعيد البحث عرض نتائج الاسم في السنة المفتوحة. الإغلاق يعرض أعداد الترحيل قبل التأكيد، والاستعادة إجراء مستقل من ملف المؤرشف. التصدير الجماعي يتبع نطاق النتائج المعروضة.

الواجهة الإنتاجية: https://quba-talents.vercel.app . مسارات API وhealth تُوجّه إلى خادم Render الخاص بالمشروع؛ لا تُحفظ مفاتيح الخدمات في الواجهة.
