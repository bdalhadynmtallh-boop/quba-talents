# موهوبين ثانوية قباء

المصدر مقسم إلى مجلدين رئيسيين فقط:

```text
quba-talents/
  frontend/       الواجهة والصفحات والثيم واختبارات المتصفح
  backend/        الخادم وقاعدة البيانات وخدمات AI وPDF والمرفقات
  README.md       هذا الدليل السريع
  package.json    أوامر تشغيل المشروع كاملًا
  compose.yaml    قاعدة PostgreSQL لتثبيت جديد
```

node_modules مجلد مولد تلقائيًا عند تثبيت الاعتماديات، وليس مجلد مصدر تحتاج تعديله.

## تشغيل النسخة الموجودة على هذا الجهاز

هذه النسخة لها إعدادات وحساب مسؤول وقاعدة بيانات موجودة؛ لا تعِد إنشاء البيئة أو الحساب ولا تشغّل قاعدة Docker ثانية على المنفذ 5432. من هذا المجلد:

```powershell
npm run dev
```

افتح http://localhost:5186. إذا توقفت قاعدة البيانات المحلية المحمولة، افتح طرفية مستقلة من هذا المجلد وشغّل:

```powershell
Set-Location ../../work/pg-runtime
node start.mjs
```

هذه الأداة محلية لهذا الجهاز، خارج الحزمة. إطفاء الجهاز يوقف المعاينة، والبيانات تبقى على القرص.

## تثبيت جديد من ZIP على جهاز آخر

يتطلب Node 24 وnpm 11 وDocker Desktop يعمل، أو PostgreSQL 17 موجودة. فك الضغط مع الحفاظ على المجلدات؛ لا تجمع ملفات frontend وbackend في الجذر. افتح الطرفية في مجلد quba-talents ونفّذ أمرًا واحدًا كل مرة، وتوقف عند أي خطأ:

```powershell
npm ci
npm run env:setup
docker compose up -d --wait
npm run db:generate
npm run db:deploy
npx playwright install chromium
npm run admin:setup
npm run dev
```

إعداد المسؤول يبني مخططات shared تلقائيًا ثم يسأل عن الاسم والبريد وكلمة مرور مخفية من 14 حرفًا على الأقل. لا يوجد حساب ثابت في ZIP. env:setup ينشئ أسرارًا عشوائية ويرفض استبدال الملفات الموجودة. إن كانت PostgreSQL موجودة اضبط اتصالها في backend/.env واترك أمر Docker.

## الذكاء الاصطناعي عبر Xkiro

افتح إعدادات الخادم، وأضف أو عدّل هذه الأسطر دون تغيير اتصال قاعدة البيانات أو سر الجلسة:

```powershell
notepad backend\.env
```

```dotenv
AI_API_KEY=ضع_مفتاح_Xkiro_هنا
AI_BASE_URL=https://api.xkiro.com/v1
AI_MODEL=qwen/qwen3.8-omni-flash:free
AI_TIMEOUT_MS=60000
AI_OUTPUT_MODE=json_object
```

أنشئ المفتاح وفق [دليل Xkiro الرسمي](https://docs.xkiro.com/guides/quickstart/). احفظ الملف وأعد تشغيل الخادم. الربط جاهز؛ لا تحتاج لصق كود OpenAI في React. تحققنا من وجود النموذج في قائمة المزود العامة في 2026-10-10، لكن لم يُختبر التوليد الحقيقي لعدم توفر المفتاح. لا ترسل المفتاح في المحادثة أو تحفظه في الواجهة. مخرجات JSON لدى Qwen في Xkiro تعليمات للنموذج وليست قيدًا مضمونًا؛ الخادم يتحقق من البنية قبل الحفظ.

## تجربة الموقع

سجّل طلبًا من /register، ثم ادخل كمسؤول واقبله من طلبات التسجيل. عدّل بيانات الطالب وأضف عملًا ومرفقًا. بعد تهيئة AI أنشئ مسودة السيرة وراجعها ثم اعتمدها لتنزيل PDF أو تصدير السير المحددة. إعدادات المدرسة والمشرفين من قائمة المسؤول. إعادة الصياغة تحفظ المعتمد حتى اعتماد المسودة الجديدة.
