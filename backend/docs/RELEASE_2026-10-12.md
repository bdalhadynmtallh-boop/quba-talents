## ما تغير

- فصل خدمات المجالات عن HTTP وتقسيم المخططات المشتركة؛ التفاصيل في `ARCHITECTURE.md`.
- حفظ رقم التواصل واسم مجمع ثانوية قباء مع قراءة السجلات القديمة التي لم يُستكمل رقمها.
- مفتاح UUID لإعادة إرسال التسجيل وبصمة المحتوى وقفل داخل المعاملة. يُرفض استعمال المفتاح بمحتوى مختلف. جلسة المتصفح تحفظ المفتاح والبصمة فقط، دون بيانات الطالب.
- علاقة الطلب بسنة تقديمه. لا تُملأ سنوات الطلبات القديمة بالتخمين؛ قبول سنة سابقة أو غير محددة يتطلب تأكيد الصف والسنة الحالية. التشابه في الاسم أو الجوال ينبه المسؤول ولا يحذف أو يدمج السجلات.
- تاريخ حذف الطالب في طلبه المعتمد، يسجله مشغل PostgreSQL حتى عند الحذف خارج الواجهة. سجل القبول السابق لا يعيد إنشاء طالب محذوف.
- جدول خاص `CvReview` للمراجع واسمه التاريخي والنسخة والبصمة والتاريخ وإقرار مراجعة الطالب بإشراف المدرسة. الاعتماد يتطلب النسخة الحالية ومصدرًا لم يتغير. المعتمد القديم يبقى قابلًا للقراءة مع بيان غياب سجل المراجعة.
- حقائق AI المكتسبة تطابق المدخلات الموثقة حرفيًا؛ النبذة والاقتراحات المستقبلية تخضع للمراجعة البشرية. توجد معاينة قبل الإرسال وحذف للأسماء المعروفة وأرقام التواصل والبريد والروابط من النصوص. الكشف الآلي لا يتعرف على كل معلومات شخصية؛ المعاينة البشرية ضرورية. بصمة المعاينة تمنع إرسال مصدر تغير بعد مراجعته.
- إصلاح فلاتر البحث وتحديث الموارد المتأثرة بالإعدادات وإخفاء المحتوى الخاص عند 401. تحسين أسماء عناصر الدخول للجوال وتباين الأزرار ورسائل التأكيد. حدود أجسام طلبات الطلاب تستوعب النصوص العربية المقبولة.
- اختبارات الكتابة تتطلب قاعدة `_test` صريحة. صور الاختبارات داخل النتائج المستثناة من Git ولا تعيد كتابة صور الوثائق.

## اعتماديات أدوات قاعدة البيانات

كانت أربعة تنبيهات عالية تتبع Prisma CLI، وتشمل `deepmerge-ts` و`mysql2`؛ لا يثبت ذلك قابلية استغلالها عبر HTTP في تطبيق PostgreSQL هذا. ثُبتت `deepmerge-ts@8.0.2` تحت `@prisma/config@7.10.0` و`mysql2@3.24.5` تحت `prisma@7.10.0` بواسطة overrides محددة، دون تغيير Prisma أو محول PostgreSQL. الإصدار الثامن يغير بعض سلوك Maps؛ إعدادات المشروع تستخدم كائنات عادية، وقد نجح التحقق من المخطط والتوليد والترحيلات والبناء والاختبارات الـ58 والثمانية بعد التحديث. أظهر `npm audit` صفر تنبيهات معروفة وقت الفحص. تراجع overrides عند تحديث Prisma وتزال إذا أصبح اعتماده الأصلي مصححًا؛ لا تستخدم `audit fix --force` لتبديل الإصدار الرئيسي عشوائيًا.
